雀魂 運解析：導入

ビルド 2026.10.22.2316。雀魂の牌譜を開いたときにクライアントが受信したデータを読むだけで、雀魂への通信は追加しません。

アプリを開く

A. ユーザースクリプト（推奨。牌譜を開くと自動でパネルが出る）

  1. PC の Chrome は Tampermonkey を入れ、拡張機能の詳細で「ユーザー スクリプトを許可する」をオン、「サイトへのアクセス」を「すべてのサイト」にする。
    iPhone の Safari は「Userscripts」アプリを入れ、「設定 → アプリ → Safari → 機能拡張 → Userscripts」で機能拡張をオンにし、game.mahjongsoul.com へのアクセスを「許可」にする。
  2. 次のリンクを開いてインストールする。以前の「雀魂 運解析 PoC（牌譜取り出し）」を入れている場合は、先に削除してください（名前が変わったため別のスクリプトとして入り、両方が動くとパネルが取り合いになります）。
    mlk-extract.user.js をインストール
  3. 雀魂で牌譜を開き、右上のパネルで「アプリで開く」を押す。

B. ブックマークレット（読み込み型・短い）

雀魂を開いた後、牌譜を開く前に実行してください。

PC：このボタンをブックマークバーへドラッグ

C. ブックマークレット（全部入り・31 KB）

B が動かないときの予備です。

PC：このボタンをブックマークバーへドラッグ
